## API Reference

### IconTile

A single surface that centers an icon, initials, or short text. Supports `asChild`.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "primary" \| "frame"` | `"default"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` |
| `fill` | `boolean` | `false` |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |

| CSS Variable | Default at `size="md"` | Description |
| --- | --- | --- |
| `--size` | `--spacing(10)` | Tile width and height. |
| `--icon-size` | `--spacing(4.5)` | Default size for child SVGs. |
