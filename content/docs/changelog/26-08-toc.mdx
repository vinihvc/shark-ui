## New component

- **Toc** — Tracks the active heading as the reader scrolls. Includes nested indent, a sliding indicator, Collapsible composition, and `useToc` / `TocRootProvider` for reading `activeIds` outside the tree. Ark UI currently marks this primitive as preview.
