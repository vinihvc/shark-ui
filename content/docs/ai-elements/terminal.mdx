## Usage

```tsx
import { Terminal, TerminalContent, TerminalHeader } from "@/components/ui/terminal";
```

```tsx
<Terminal>
  <TerminalHeader>zsh · pnpm test</TerminalHeader>
  <TerminalContent output={"\u001B[32m✓\u001B[0m All tests passed"} />
</Terminal>
```

`TerminalContent` maps a small set of ANSI colors (`31`, `32`, `33`, `34`, `36`, `90`) onto semantic text tokens. Use this as the result of a `Shell` [Tool](/docs/ai-elements/tool).
