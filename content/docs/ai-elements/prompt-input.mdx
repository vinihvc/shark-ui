## Anatomy

```text
PromptInput
├── PromptInputHeader
├── PromptInputTextarea
└── PromptInputFooter
    ├── PromptInputTools
    │   └── PromptInputButton
    └── PromptInputSubmit
```

## Usage

```tsx
import {
  PromptInput,
  PromptInputFooter,
  PromptInputSubmit,
  PromptInputTextarea,
  PromptInputTools,
} from "@/components/ui/prompt-input";
```

```tsx
<PromptInput onSubmit={({ text }) => send(text)} onStop={stop}>
  <PromptInputTextarea aria-label="Message" />
  <PromptInputFooter>
    <PromptInputTools />
    <PromptInputSubmit />
  </PromptInputFooter>
</PromptInput>
```

`PromptInput` is a form around [Input Group](/docs/components/input-group). Enter submits, Shift+Enter inserts a new line.

## Attachments

Wrap the composer in [File Upload](/docs/components/file-upload) and place chips in `PromptInputHeader`. Use `FileUploadTrigger` with `asChild` on `PromptInputButton`.

## API Reference

### PromptInput

Form around [Input Group](/docs/components/input-group). Enter submits, Shift+Enter inserts a new line.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"ready" \| "submitted" \| "streaming" \| "error"` | `"ready"` |
| `onSubmit` | `(detail: { text: string; event: FormEvent }) => void` | `-` |
| `onStop` | `() => void` | `-` |
| `className` | `string` | `-` |

### PromptInputHeader

Addon above the textarea. Place attachment chips here.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputTextarea

Message field. Submits on Enter unless `status` is `"submitted"` or `"streaming"`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputFooter

Addon below the textarea for tools and submit.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputTools

Container for composer actions.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputButton

Tool button. Alias of [InputGroupButton](/docs/components/input-group).

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"ghost"` |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"xs"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PromptInputSubmit

Send control. Shows a spinner for `"submitted"` and a stop control for `"streaming"`.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"default"` |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"icon-sm"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
