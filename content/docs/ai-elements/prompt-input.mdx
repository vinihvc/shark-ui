## Usage

```tsx
import {
  PromptInput,
  PromptInputFooter,
  PromptInputSubmit,
  PromptInputTextarea,
  PromptInputTools,
} from "@/components/ui/prompt-input";
```

```tsx
<PromptInput onSubmit={({ text }) => send(text)} onStop={stop}>
  <PromptInputTextarea aria-label="Prompt" />
  <PromptInputFooter>
    <PromptInputTools />
    <PromptInputSubmit />
  </PromptInputFooter>
</PromptInput>
```

`PromptInput` is a form around [Input Group](/docs/components/input-group). Compose actions with `PromptInputActions` and a [Model Selector](/docs/ai-elements/model-selector) in the footer. Enter submits, Shift+Enter inserts a new line.

## API Reference

### PromptInput

Form around [Input Group](/docs/components/input-group). The textarea sits above a footer toolbar inside the same field. Enter submits, Shift+Enter inserts a new line.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"ready" \| "submitted" \| "streaming" \| "error"` | `"ready"` |
| `onSubmit` | `(detail: { text: string; event: FormEvent }) => void` | `-` |
| `onStop` | `() => void` | `-` |
| `className` | `string` | `-` |

### PromptInputHeader

Addon above the textarea. Place attachment chips here.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputTextarea

Message field. Submits on Enter unless `status` is `"submitted"` or `"streaming"`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputFooter

Addon below the textarea for tools and submit.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputTools

Container for composer actions.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputActions

Popover for attach and context actions. Built on [Popover](/docs/components/popover). Open it with `PopoverTrigger` and `asChild` on a `PromptInputButton`.

| Prop | Type | Default |
| --- | --- | --- |
| `modal` | `boolean` | `false` |
| `className` | `string` | `-` |

### PromptInputAction

Action row inside `PromptInputActionsContent`. Closes the popover on select.

| Prop | Type | Default |
| --- | --- | --- |
| `icon` | `ReactNode` | `-` |
| `description` | `ReactNode` | `-` |
| `className` | `string` | `-` |

### PromptInputButton

Tool button. Alias of [InputGroupButton](/docs/components/input-group).

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"ghost"` |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"xs"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PromptInputSubmit

Send control. Uses an up arrow when ready, a spinner for `"submitted"`, and a stop control for `"streaming"`. Disabled while the textarea is empty unless streaming.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"default"` |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"icon-sm"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
