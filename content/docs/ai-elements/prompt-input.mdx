## Anatomy

```text
PromptInput
├── PromptInputHeader
├── PromptInputTextarea
└── PromptInputFooter
    ├── PromptInputTools
    │   └── PromptInputButton
    └── PromptInputSubmit
```

## Usage

```tsx
import {
  PromptInput,
  PromptInputFooter,
  PromptInputSubmit,
  PromptInputTextarea,
  PromptInputTools,
} from "@/components/ui/prompt-input";
```

```tsx
<PromptInput onSubmit={({ text }) => send(text)} onStop={stop}>
  <PromptInputTextarea aria-label="Message" />
  <PromptInputFooter>
    <PromptInputTools />
    <PromptInputSubmit />
  </PromptInputFooter>
</PromptInput>
```

`PromptInput` is a form around [Input Group](/docs/components/input-group). Enter submits, Shift+Enter inserts a new line.

## Attachments

Wrap the composer in [File Upload](/docs/components/file-upload) and place chips in `PromptInputHeader`. Use `FileUploadTrigger` with `asChild` on `PromptInputButton`.

## API Reference

### PromptInput

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"ready" \| "submitted" \| "streaming" \| "error"` | `"ready"` |
| `onSubmit` | `(detail: { text: string; event: FormEvent }) => void` | — |
| `onStop` | `() => void` | — |

`PromptInputSubmit` shows a spinner for `submitted` and a stop control for `streaming`.
