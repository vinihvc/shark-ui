## Usage

```tsx
import {
  Tool,
  ToolContent,
  ToolName,
  ToolStatusBadge,
  ToolTrigger,
} from "@/components/ui/tool";
```

```tsx
<Tool status="running">
  <ToolTrigger>
    <ToolName>Read</ToolName>
    <ToolStatusBadge status="running" />
  </ToolTrigger>
  <ToolContent />
</Tool>
```

Compose with [Confirmation](/docs/ai-elements/confirmation) when a tool needs approval before it runs.

## Status

<ComponentPreview componentName="tool" fileName="example-status" />

| Status | Description |
| --- | --- |
| `pending` | Queued, not started. |
| `running` | In progress. Opens by default. |
| `completed` | Finished successfully. |
| `error` | Failed. |

## API Reference

### Tool

| Prop | Type | Default |
