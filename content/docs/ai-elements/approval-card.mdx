## Usage

```tsx
import { ApprovalCard } from "@/components/ui/approval-card";
```

```tsx
<ApprovalCard
  variant="plan"
  planTitle="Session auth migration"
  plan={steps}
  onApprove={() => {}}
  onReject={() => {}}
/>
```

Variants: `questions`, `command`, and `plan`. Keep [Confirmation](/docs/ai-elements/confirmation) for simple tool accept or reject.
