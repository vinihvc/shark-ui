## Anatomy

```text
Plan
├── PlanHeader
│   ├── PlanTitle
│   ├── PlanDescription
│   └── PlanAction
│       └── PlanTrigger
└── PlanContent
    └── Task
```

## Usage

```tsx
import {
  Plan,
  PlanAction,
  PlanContent,
  PlanHeader,
  PlanTitle,
  PlanTrigger,
} from "@/components/ui/plan";
```

```tsx
<Plan>
  <PlanHeader>
    <PlanTitle>Add email validation</PlanTitle>
    <PlanAction>
      <PlanTrigger />
    </PlanAction>
  </PlanHeader>
  <PlanContent />
</Plan>
```

Compose [Task](/docs/ai-elements/task) inside `PlanContent`.

## API Reference

`Plan` forwards Collapsible props. `defaultOpen` is `true`.
