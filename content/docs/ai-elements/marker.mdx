## Variants

Use `variant` to switch between an inline marker, bordered row, and labeled separator.

<ComponentPreview componentName="marker" fileName="example-variants" />

| Variant | Description |
| --- | --- |
| `default` | An inline marker for status, notes, and actions. |
| `border` | A default marker with a bottom border under the row. |
| `separator` | A centered label with divider lines on each side. |

## Links and Buttons

Turn a marker into a link or button with `asChild` on `Marker`.

<ComponentPreview componentName="marker" fileName="example-links" />

```tsx
<Marker asChild>
  <a href="#">
    <MarkerContent>View the pull request</MarkerContent>
  </a>
</Marker>
```

## API Reference

### Marker

Root status line, bordered row, or labeled separator.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### MarkerIcon

Decorative icon slot.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### MarkerContent

Label text for the marker.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
