## Usage

```tsx
import { SpeechInput } from "@/components/ui/speech-input";
```

```tsx
<SpeechInput onTranscriptionChange={(text) => append(text)} />
```

Uses the browser Web Speech API when available. The control is disabled with a tooltip when speech recognition is unsupported. Requires a secure context (HTTPS or localhost).
