## Anatomy

```text
Task
└── TaskItem
    ├── TaskItemTrigger
    └── TaskItemContent
        └── TaskItemDetail
            └── TaskItemDetailFile
```

## Usage

```tsx
import {
  Task,
  TaskItem,
  TaskItemContent,
  TaskItemDetail,
  TaskItemDetailFile,
  TaskItemTrigger,
} from "@/components/ui/task";
```

```tsx
<Task completed={1} total={3}>
  <TaskItem status="in-progress">
    <TaskItemTrigger title="Patch isValidEmail" />
    <TaskItemContent>
      <TaskItemDetail>
        Updating <TaskItemDetailFile>src/utils/helpers.ts</TaskItemDetailFile>
      </TaskItemDetail>
    </TaskItemContent>
  </TaskItem>
</Task>
```

## API Reference

### Task

Groups related task items and can show their overall progress.

| Prop | Type | Default |
| --- | --- | --- |
| `completed` | `number` | `-` |
| `total` | `number` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TaskItem

A collapsible unit of work with a status and optional details.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"pending" \| "in-progress" \| "completed" \| "error"` | `"pending"` |
| `className` | `string` | `-` |

### TaskItemTrigger

Toggles the item and, by default, displays its status, title, and indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | **required** |
| `status` | `"pending" \| "in-progress" \| "completed" \| "error"` | inherits `TaskItem` status |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TaskItemContent

Contains the details revealed when the item is open.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TaskItemDetail

A supporting line for progress, context, files, or custom content.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TaskItemDetailFile

A compact file reference for use inside a task detail.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "outline" \| "success" \| "info" \| "warning" \| "destructive"` | `"outline"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
