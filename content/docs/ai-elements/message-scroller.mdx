Built on Ark UI [Scroll Area](https://ark-ui.com/docs/components/scroll-area). It jumps to the start or end of the thread. It does not auto-follow a stream, restore a saved position, or preserve scroll when older messages prepend.

## Usage

```tsx
import {
  MessageScroller,
  MessageScrollerButton,
  MessageScrollerContent,
  MessageScrollerItem,
  MessageScrollerViewport,
} from "@/components/ui/message-scroller";
```

```tsx
<MessageScroller className="h-96">
  <MessageScrollerViewport>
    <MessageScrollerContent>
      <MessageScrollerItem />
    </MessageScrollerContent>
  </MessageScrollerViewport>
  <MessageScrollerButton />
</MessageScroller>
```

The viewport uses the same edge fade as [Scroll Area](/docs/components/scroll-area) (`scrollFade`).

## Jump controls

Give `MessageScrollerButton` `direction="start"` or `direction="end"`. The control hides when that edge is already in view.

## API Reference

### MessageScroller

Root scroll area for a transcript. Forwards [Scroll Area](/docs/components/scroll-area) root props.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

| Attribute | Default |
| --- | --- |
| `--fade-size` | `1.5rem` |

### MessageScrollerViewport

Scrollable viewport with edge fade masks.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### MessageScrollerContent

Column of messages inside the viewport.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### MessageScrollerItem

A single message row. Uses `content-visibility` for long threads.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### MessageScrollerButton

Jump control. Built on [Button](/docs/components/button). Hides when that edge is already in view.

| Prop | Type | Default |
| --- | --- | --- |
| `direction` | `"start" \| "end"` | `"end"` |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"secondary"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "icon-xs" \| "icon-sm" \| "icon-md" \| "icon-lg" \| "icon-xl"` | `"icon-sm"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
