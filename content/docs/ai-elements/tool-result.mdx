## Usage

```tsx
import {
  ToolResult,
  ToolResultContent,
  ToolResultMeta,
  ToolResultName,
  ToolResultTitle,
  ToolResultTrigger,
} from "@/components/ui/tool-result";
```

```tsx
<ToolResult status="success">
  <ToolResultTrigger>
    <ToolResultTitle>Tests passed</ToolResultTitle>
    <ToolResultMeta>2.9s</ToolResultMeta>
    <ToolResultName>terminal.run</ToolResultName>
  </ToolResultTrigger>
  <ToolResultContent />
</ToolResult>
```

## API Reference

### ToolResult

Root [Collapsible](/docs/components/collapsible). `aria-busy` is set while `status` is `"running"`. `defaultOpen` is `true` when `status` is `"running"`.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"running" \| "success" \| "error" \| "cancelled"` | `"success"` |
| `defaultOpen` | `boolean` | `true` when `status` is `"running"` |
| `className` | `string` | `-` |

### ToolResultTrigger

Toggles the result. Renders children, then status and the chevron.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultTitle

Primary label in the trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultMeta

Secondary text such as duration.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultName

Tool name in the trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultStatus

Status icon and label. Children replace the default label.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

| Status | Label |
| --- | --- |
| `running` | Running |
| `success` | Completed |
| `error` | Failed |
| `cancelled` | Cancelled |

### ToolResultContent

Holds [Terminal](/docs/ai-elements/terminal) or [Diff](/docs/ai-elements/diff).

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
