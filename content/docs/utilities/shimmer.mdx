## Examples

### Duration

Use `shimmer-duration-*` to set the duration of one sweep in milliseconds.

<ComponentPreview componentName="shimmer" fileName="example-duration" />

### Spread

Use `shimmer-spread-*` to set the width of the highlight band using the spacing scale.

<ComponentPreview componentName="shimmer" fileName="example-spread" />

### Angle

Use `shimmer-angle-*` to set the tilt of the highlight band in degrees.

<ComponentPreview componentName="shimmer" fileName="example-angle" />

### Reverse

Use `shimmer-reverse` to sweep the highlight in the opposite direction. In RTL layouts the sweep already follows the reading direction.

<ComponentPreview componentName="shimmer" fileName="example-reverse" />

### Custom Color

Use `shimmer-color-*` to set the highlight color explicitly.

<ComponentPreview componentName="shimmer" fileName="example-color" />

### Play Once

Use `shimmer-once` to play a single sweep instead of looping.

<ComponentPreview componentName="shimmer" fileName="example-once" />

### Disabling the Shimmer

Use `shimmer-none` to turn the effect off and render the text normally.

<ComponentPreview componentName="shimmer" fileName="example-none" />

> You can use breakpoint utilities to disable the shimmer at different screen sizes.

```css
  shimmer md:shimmer-none
```

## API Reference

| Class | Effect | Default |
| --- | --- | --- |
| `shimmer` | Sweep highlight across text | - |
| `shimmer-once` | Play a single cycle | - |
| `shimmer-reverse` | Reverse the sweep | - |
| `shimmer-none` | Disable the effect | - |
| `shimmer-color-*` | Set highlight color | - |
| `shimmer-duration-*` | Sweep duration in milliseconds | `2000` (`2s`) |
| `shimmer-spread-*` | Highlight band width | `calc(3ch + 40px)` |
| `shimmer-angle-*` | Highlight tilt in degrees | `20` |
