# Blocks catalog

Scope: the public blocks catalog and its category routes. Visitor mode: Read, with a focused inspect-and-copy task.

THESIS: A block catalog should feel like a live registry specimen, not a marketing gallery or a grid of screenshots.

OWN-WORLD: Preserve Shark UI's neutral semantic surfaces, restrained borders, compact controls, heading face, and single theme accent; the live product composition is the material.

STORY: Visitors discover a composition by search or category in the catalog rail, land on a live preview, inspect files, then copy or install.

FIRST VIEWPORT: Desktop catalog rail: search, then categories with counts. Main pane has no hero title or description. The live viewer leads, with block name and install command. A compact horizontal picker appears only when more than one block is in view. On narrow screens the rail is a left Sheet from a sticky bar that also shows the active block name.

FORM: Registry workspace with a dense navigation rail, concise context, and one active live specimen; seed key `559a84bf`, generated by Impeccable concept-seed and constrained back to the user-specified Shark UI catalog.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Constraints: English UI, static export, interactive iframes on mobile, source-first copy/install, existing Shark UI identity, no reclassification of legacy chart/sidebar previews, and no Favorites, fabricated categories, or unsupported controls.
