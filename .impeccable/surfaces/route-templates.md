# Templates catalog

Scope: the public templates catalog and its first AI chat starter. Visitor mode: Persuade until the live showcase, then Operate inside the preview.

THESIS: The template is the proof: a bold promise gives way to a complete, live, source-backed product shell within the first scroll.

OWN-WORLD: Inherit Shark UI's neutral semantic surfaces, Hanken Grotesk hierarchy, compact controls, restrained borders, proportional radii, and single configurable accent.

STORY: Developers understand the value of a complete starter, see the real stack behind it, exercise its local interactions, inspect every file, then copy or install it.

FIRST VIEWPORT: A centered, oversized product statement fills most of the framed canvas, followed by an honest technical stack and the opening edge of the live AI Chat showcase. The primary action jumps directly to the working template.

FORM: User-pinned editorial catalog inspired by the supplied Magic UI Pro reference, translated into Shark UI's established visual world. A concept roll is not applicable because the reference fixes the direction.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Memorable moment: the marketing-scale headline gives way to a real, theme-synchronized application that can immediately switch from Preview to Code.

Constraints: English UI, static export, same-origin interactive iframe, truthful product language, local deterministic chat behavior, no AI SDK or backend, and no public category/search layer in v1. Do not introduce pricing, testimonials, or performance claims from the visual reference.

## Shipped route invariants

- **Hero topology:** Keep the route framed by the standard centered container and vertical border rails. The first band is a near-viewport-height centered composition: editorial display promise, supporting copy, primary and secondary actions, technical stack proof, then the announcement. At the shipped breakpoints the promise uses 3rem, 3.75rem, 4.5rem, and 6rem steps; this is the `/templates` expression of the global Editorial Display role, not a new type family.
- **Post-proof announcement:** The “AI Chat template is now available” announcement follows the stack list. It confirms the concrete release only after the page establishes what the starter includes; do not float it above the promise or use it as pre-hero chrome.
- **Workbench reveal:** The first catalog band opens immediately after the hero and reveals the complete Composition Viewer as it enters the viewport. The reveal is a restrained one-second fade, upward translation, and blur resolution tied to view progress; reduced-motion users receive the workbench without that transition.
- **Seeded preview:** The first live frame must open on the deterministic “Launch plan” conversation, including the illustrative attachment and a rich assistant response (reasoning, tool, confirmation/approval, plan, sources, and message actions). The populated state proves message layout and content handling before the visitor interacts; New chat may still expose the empty state with suggestions, and local sends must remain deterministic and explicitly backend-free.
- **Source-backed proof:** Preview, Code, responsive viewport controls, file navigation, copy, and the `@shark/ai-chat-01` install command remain one composition. The primary hero action targets this working proof directly; the closing Blocks action is secondary and appears only after the full-template experience.
